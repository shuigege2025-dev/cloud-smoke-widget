# 云抽烟小组件 · 音效资源

本目录所有 `.wav` 音效均由 `tools/generate-sounds.cjs` **程序化合成**（白噪声 + 滤波 + 包络），
为 100% 原创内容，不包含任何第三方采样，可自由使用、修改与商用（CC0）。

| 文件 | 用途 | 说明 |
|---|---|---|
| `light.wav` | 点击点燃 | 打火机咔嗒 + 点火气流 + 轻微噼啪燃烧 |
| `burn-loop.wav` | 燃烧循环 | 首尾淡入淡出，可无缝循环的低强度噼啪声 |
| `inhale.wav` | 深吸一口 | 吸气气流声（低通 + 气息高频层） |
| `ash.wav` | 弹烟灰 | 手指敲击 + 烟灰颗粒洒落 |
| `exhale.wav` | 吐烟圈 | 呼气声（低频 + 胸腔共鸣层） |
| `switch.wav` | 换一根 | 轻弹出盒 + 双音 blip |

重新生成：`node tools/generate-sounds.cjs`
